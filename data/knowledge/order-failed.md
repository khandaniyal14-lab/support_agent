# Troubleshooting: Order Failed to Complete

**Solara Home Electronics**

If you tried to place an order and it didn't go through — or you're not sure whether it did — follow these steps.

## Step 1: Check Whether the Order Actually Went Through

- Check your email (including spam/promotions folders) for an order confirmation from orders@solarahome.com.
- Log in to **My Orders** and check whether the order appears in your history.
- Check your bank/card app for a completed charge (not just a pending authorization) from "SOLARA HOME ELEC."

If you see a confirmation email or the order in **My Orders**, your order was placed successfully — no further action needed.

## Step 2: Identify the Error

| Symptom | Likely Cause | What to Do |
|---|---|---|
| "Something went wrong" generic error at final checkout step | Temporary site/gateway issue | Wait 1–2 minutes, refresh, and retry |
| Page freezes on "Processing Order" | Network interruption during submission | Do not click submit multiple times; wait 5 minutes, then check My Orders before retrying |
| "Item no longer available" | Item sold out between adding to cart and checkout | Remove the item or select a similar in-stock alternative |
| "Unable to verify shipping address" | Address doesn't match USPS/carrier database format | Re-enter the address using the autocomplete suggestion, or contact Support for a manual override |
| Cart empties unexpectedly | Session timeout (carts expire after 60 minutes of inactivity) | Re-add items; consider creating an account so cart contents are saved |
| Payment step won't load | Ad blocker, outdated browser, or connectivity issue | See [Payment Failed troubleshooting](payment-failed.md) |

## Step 3: Avoid Duplicate Orders

If an error occurs after you've already clicked "Place Order," **do not click it again**. Instead, check **My Orders** or your email first — clicking multiple times can occasionally result in duplicate orders, which we're happy to cancel one of if this happens (contact Support right away).

## Step 4: Try a Clean Environment

- Switch to a different browser (Chrome, Safari, Firefox, or Edge, updated to the latest version) or try the Solara mobile app.
- Disable browser extensions, especially ad blockers and privacy/VPN extensions.
- Try switching from Wi-Fi to mobile data (or vice versa) if you suspect a network issue.

## Step 5: Pre-Order and Backorder Specific Issues

If you're trying to place a pre-order and receive an "allocation limit reached" message, this means the current release batch is fully reserved. You can join the waitlist on the product page to be notified when the next batch opens.
